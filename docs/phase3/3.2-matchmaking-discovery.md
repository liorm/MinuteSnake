# Phase 3.2: Matchmaking & Discovery

## Objective
Implement advanced room discovery, intelligent matchmaking, and support for private rooms with invitation codes.

## Tasks

### Room Discovery System
1. **Room Listing Service**
   - Public room browser with filters
   - Real-time room status updates
   - Search and sorting capabilities
   - Room metadata display (player count, skill level, etc.)

2. **Intelligent Matchmaking**
   - Skill-based matching algorithms
   - Latency-based room selection
   - Player preference matching
   - Queue system for optimal matches

3. **Private Room System**
   - Generate unique invitation codes
   - Code-based room joining
   - Room privacy settings and controls
   - Friend invitation system

4. **Room Categories**
   - Casual vs competitive modes
   - Different game variants
   - Skill-based lobbies
   - Custom rule sets

## Technical Specifications

### Room Discovery Service
```typescript
interface PublicRoomInfo {
  roomId: string
  roomName: string
  playerCount: number
  maxPlayers: number
  skillLevel: SkillLevel
  gameMode: GameMode
  status: RoomStatus
  averageLatency: number
  region: string
  hasPassword: boolean
}

interface RoomFilter {
  skillLevel?: SkillLevel[]
  gameMode?: GameMode[]
  maxLatency?: number
  playerCountRange?: [number, number]
  region?: string
  excludeFull?: boolean
}

class RoomDiscoveryService {
  async findRooms(filter: RoomFilter): Promise<PublicRoomInfo[]>
  async quickMatch(playerProfile: PlayerProfile): Promise<RoomJoinResult>
  async createRoom(config: RoomCreationConfig): Promise<string>
  async joinRoom(roomId: string, password?: string): Promise<RoomJoinResult>
}
```

### Matchmaking System
```typescript
interface PlayerProfile {
  playerId: string
  skillRating: number
  preferredLatency: number
  gameMode: GameMode[]
  region: string
  playStyle: PlayStyle
}

interface MatchmakingCriteria {
  skillRange: number
  maxLatency: number
  preferredGameMode: GameMode
  maxWaitTime: number
}

class MatchmakingEngine {
  async findMatch(profile: PlayerProfile): Promise<MatchResult>
  async joinQueue(profile: PlayerProfile, criteria: MatchmakingCriteria): Promise<void>
  async leaveQueue(playerId: string): Promise<void>
  
  private calculateCompatibility(p1: PlayerProfile, p2: PlayerProfile): number
  private selectOptimalRoom(rooms: PublicRoomInfo[], profile: PlayerProfile): PublicRoomInfo
}

interface MatchResult {
  success: boolean
  roomId?: string
  estimatedWaitTime?: number
  queuePosition?: number
}
```

### Private Room System
```typescript
interface PrivateRoomConfig {
  roomName: string
  password?: string
  inviteOnly: boolean
  maxPlayers: number
  gameMode: GameMode
  customRules?: GameRules
}

class PrivateRoomManager {
  async createPrivateRoom(config: PrivateRoomConfig): Promise<PrivateRoomResult>
  async generateInviteCode(roomId: string): Promise<string>
  async joinByInviteCode(code: string, playerId: string): Promise<RoomJoinResult>
  async inviteFriend(roomId: string, friendId: string): Promise<void>
}

interface PrivateRoomResult {
  roomId: string
  inviteCode: string
  roomUrl: string
}
```

enum GameMode {
