# Phase 1.2: Room Durable Object with WebSockets

## Objective
Replace the basic `MyDurableObject` with a `GameRoomObject` that handles WebSocket connections and basic room management.

## Tasks

### Core Implementation
1. **Replace MyDurableObject**
   - Rename class to `GameRoomObject`
   - Update wrangler.jsonc configuration
   - Update TypeScript types

2. **WebSocket Handling**
   - Implement WebSocket accept logic
   - Handle incoming WebSocket connections
   - Manage connection state and cleanup

3. **Room Lifecycle**
   - Room creation logic
   - Player join functionality
   - Player leave handling
   - Room cleanup when empty

4. **Connection Management**
   - Store active WebSocket connections
   - Player identification system
   - Connection heartbeat/ping handling
   - Graceful disconnection handling

## Technical Specifications

### GameRoomObject Interface
```typescript
class GameRoomObject extends DurableObject {
  // WebSocket connection management
  async handleWebSocket(request: Request): Promise<Response>
  
  // Room lifecycle
  async createRoom(roomId: string): Promise<void>
  async joinRoom(playerId: string): Promise<boolean>
  async leaveRoom(playerId: string): Promise<void>
  
  // Connection management
  private connections: Map<string, WebSocket>
  private players: Map<string, PlayerInfo>
}
```

## Deliverables
- Updated `GameRoomObject` class
- WebSocket connection handling
- Basic room management functionality
- Updated wrangler configuration

## Success Criteria
- WebSocket connections can be established
- Multiple players can join the same room
- Players can leave rooms gracefully
- Connections are properly cleaned up on disconnect
